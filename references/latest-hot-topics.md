# 最新热点发现与筛选

## 目标

每个新内容任务先回答三个问题：

1. 现在 24–72 小时内真正正在发酵的热点是什么？
2. 哪个热点适合做高共鸣金句图？
3. 哪个热点已有足够事实和视频素材，不会变成“只有情绪没有事件”的内容？

## 推荐来源

至少查看两个来源，优先三个：

- 微博热搜榜：`https://s.weibo.com/top/summary`
- 抖音热点榜、热榜、创作者中心热点或站内热门话题
- 今日头条热榜：`https://www.toutiao.com/hot-event/hot-board/`
- 知乎热榜、B站热门、微信指数或同类平台
- 权威新闻客户端、官方媒体、当事机构账号

不要默认使用百度热搜。只有用户明确要求百度时，才把百度加入来源。

平台页面和算法会变化。若直接 URL 失效，使用站内可见入口，不循环猜测 URL。

## 采集字段

每个候选必须写入状态文件：

```json
{
  "title": "热点短标题",
  "event_date": "YYYY-MM-DD",
  "first_seen_at": "YYYY-MM-DDTHH:MM:SS+08:00",
  "discovered_at": "YYYY-MM-DDTHH:MM:SS+08:00",
  "age_hours": 12,
  "source_urls": ["https://..."],
  "heat_evidence": "微博热搜第 3；抖音热点榜第 5",
  "fact_status": "confirmed",
  "fact_note": "官方媒体已确认，当事人已回应",
  "video_candidates": 3,
  "elimination_reason": null
}
```

`fact_status` 只允许：

- `confirmed`：权威来源已确认。
- `developing`：事件仍在发展，但核心事实已有多源确认。
- `rumor_denied`：传言存在且已有权威辟谣，可做“为什么大家会信”的角度。
- `unverified`：默认淘汰，不得进入出图阶段。

## 新鲜度门

| 年龄 | 处理 |
|---|---|
| 0–24 小时 | 优先，热度通常仍在上升 |
| 24–72 小时 | 可用，但必须有新进展、持续热榜或明确讨论增量 |
| 72 小时以上 | 默认淘汰 |
| 有全新权威进展 | 按新进展时间重新计算，可使用 |
| 用户明确要求回顾 | 可使用，但不得宣称为“最新热点” |

发布前重新计算 `age_hours`。如果等待登录或用户确认期间超过阈值，退回热点选择阶段，不要默认放行。

## 评分

按 100 分排序：

- 时效性 30：越新越高。
- 热度 25：热榜排名、讨论量和扩散速度。
- 共鸣 20：与婚恋、就业、收入、代际、城市生活、普通人的现实压力高度相关。
- 可核验 15：权威来源、官方回应、原始材料是否充分。
- 可视频化 10：能找到口播、访谈或烧录字幕素材。

低于 70 分不进入视频获取。

## 推荐与淘汰

优先：

- 普通人有真实经历和强共鸣的社会议题
- 已经形成两派讨论但事实边界清楚的事件
- 官方、当事方或权威媒体已经回应的传言
- 能在一句话内说明“发生了什么”的热点

淘汰：

- 超过 72 小时且无新进展
- 只有标题党截图，找不到原始来源
- 灾害、事故、伤亡、血腥、未成年人隐私
- 未经证实的刑事指控、个人隐私、网暴对象
- 医疗诊断、金融荐股、投资承诺
- 低俗猎奇、地域攻击、性别仇恨
- 不适合原生字幕或无法获得合法素材

## 选题输出

最终选择写到 `workflow-state.json`：

```json
{
  "topic": {
    "title": "AI伪造彩礼贷海报",
    "event_date": "2026-08-26",
    "first_seen_at": "2026-08-26T22:00:00+08:00",
    "discovered_at": "2026-09-10T16:00:00+08:00",
    "age_hours": 354,
    "source_urls": ["..."],
    "heat_evidence": "...",
    "fact_status": "rumor_denied",
    "fact_note": "银行已发声明并报案",
    "video_candidates": 1,
    "freshness_decision": "expired",
    "elimination_reason": "超过72小时且无新进展"
  }
}
```

上述示例只说明结构。`freshness_decision=expired` 时不得进入 `source_ready`。

## 标题一致性检查

发布前必须同时满足：

- 标题提到具体事件对象。
- 正文前两段解释发生了什么。
- 来源与正文结论一致。
- 没有把“网传”写成“已经发生”。
- 没有把“辟谣”写成“默认承认”。
- 没有使用无法核验的绝对化表述。
