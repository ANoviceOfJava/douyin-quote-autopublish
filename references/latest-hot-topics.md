# 最新热点发现与筛选

## 目标

每个新内容任务先回答三个问题：

1. 现在 24–72 小时内真正正在发酵的热点是什么？
2. 哪个热点适合制作独立封面和高共鸣正文四图？
3. 哪个热点已有足够事实和视频素材，不会变成“只有情绪没有事件”的内容？

## 话题度硬门

“热”只说明曝光高，不代表话题度高。话题度高的话题必须能持续激发讨论，至少满足以下一项：

- 有明确争议、利益冲突或道德分歧，评论区会自然站队。
- 有明星、公众人物、品牌或机构效应，并且出现了发言、回应、道歉、处罚或反转。
- 事件存在反转、前后矛盾、责任归属争议，适合追问“谁对谁错、谁该负责”。
- 相关搜索和相关视频持续出现“回应、争议、反转、道歉、站队、谁负责”等扩展词。
- 出现大量二创、玩梗、跟拍、模仿或评论区争论，而不只是单向转发。

每个候选必须写出 `discussion_hook`：一句话说明这条内容会让网友讨论什么。无法写出讨论钩子，或只能回答“大家会觉得很感动/很励志”，则不算高话题度。

明星效应可以作为合格话题度来源，但必须基于公开发言、公开行为、作品争议、品牌互动或当事方回应；不得把未经证实的恋爱、私生活或八卦猜测写成事实。

以下情况不能仅凭热榜排名入选：

- 单纯政策提醒、办事指南和放假通知。
- 企业发布建设计划、产品参数、展会成果。
- 无争议的正能量故事、动物奇闻、个人励志奇迹。
- 播放量或点赞量很高，但评论只有祝福、围观或单一情绪，没有观点分歧。

## 来源优先级

抖音站内是硬门，必须先查，不能用站外热榜替代：

1. 抖音官方热点榜：`https://www.douyin.com/hot`
2. 抖音热榜、创作者中心热点榜、热门话题和热门视频
3. 抖音站内搜索及其“相关搜索”
4. 微博、今日头条、B站、知乎等站外平台，用于交叉核验和补充
5. 权威媒体、官方账号或当事机构，用于事实核验

品牌、产品、功能或消费争议类话题可能先在抖音搜索和相关推荐中爆发，却不进入当刻热榜 Top 榜。仅查热榜接口会漏题。每次扫描都必须对候选词和类别种子执行站内搜索，具体流程见 [douyin-topic-discovery.md](douyin-topic-discovery.md)。

不要默认使用百度热搜。只有用户明确要求百度时，才把百度加入来源。

平台页面和算法会变化。若直接 URL 失效，使用站内可见入口，不循环猜测 URL。

## 采集字段

每个候选必须写入状态文件：

```json
{
  "title": "热点短标题",
  "event_date": "YYYY-MM-DD",
  "first_seen_at": "YYYY-MM-DDTHH:MM:SS+08:00",
  "discovered_at": "YYYY-MM-DDTHH:MM:SS+08:00",
  "age_hours": 12,
  "source_urls": ["https://..."],
  "heat_evidence": "抖音热点榜第 5；抖音站内搜索相关词已形成事件；微博热搜第 3",
  "topic_score": {
    "total": 27,
    "max": 30,
    "signals": ["明星/品牌公开争执", "评论区分歧明显", "相关搜索出现回应与站队"]
  },
  "discussion_hook": "一句主观差评，品牌该不该公开回应",
  "douyin_evidence": {
    "hot_board_rank": 5,
    "hot_value": 7752000,
    "search_query": "关键词",
    "related_searches": ["相关搜索1", "相关搜索2"],
    "recent_video_examples": []
  },
  "fact_status": "confirmed",
  "fact_note": "官方媒体已确认，当事人已回应",
  "video_candidates": 3,
  "elimination_reason": null
}
```

`fact_status` 只允许：

- `confirmed`：权威来源已确认。
- `developing`：事件仍在发展，但核心事实已有多源确认。
- `rumor_denied`：传言存在且已有权威辟谣，可做“为什么大家会信”的角度。
- `unverified`：默认淘汰，不得进入出图阶段。

## 新鲜度门

| 年龄 | 处理 |
|---|---|
| 0–24 小时 | 优先，热度通常仍在上升 |
| 24–72 小时 | 可用，但必须有新进展、持续热榜或明确讨论增量 |
| 72 小时以上 | 默认淘汰 |
| 有全新权威进展 | 按新进展时间重新计算，可使用 |
| 用户明确要求回顾 | 可使用，但不得宣称为“最新热点” |

发布前重新计算 `age_hours`。如果等待登录或用户确认期间超过阈值，退回热点选择阶段，不要默认放行。

## 评分

按 100 分排序：

- 时效性 20：越新越高。
- 话题度 30：争议、站队、反转、明星/公众人物/品牌效应、二创扩散和评论讨论强度。
- 抖音站内热度 15：热榜排名、搜索热点、相关搜索、讨论量和扩散速度；站外热度只能加分，不能替代站内证据。
- 共鸣 15：与婚恋、就业、收入、代际、城市生活、普通人的现实压力高度相关。
- 可核验 10：权威来源、官方回应、原始材料是否充分。
- 可视频化 10：能找到口播、访谈或烧录字幕素材。

总分低于 70 不进入视频获取；话题度低于 20/30 时，无论总分多少都直接淘汰。

## 推荐与淘汰

优先：

- 评论区已经形成两派讨论、站队或责任归属争议的事件
- 明星、公众人物、品牌或机构公开回应、道歉、互怼或反转
- 普通人有真实经历和强共鸣，同时存在明确分歧的社会议题
- 官方、当事方或权威媒体已经回应的传言或消费争议
- 能在一句话内说明“发生了什么”和“大家为什么会吵”的热点

淘汰：

- 只有热榜排名或播放量，写不出讨论钩子的话题
- 单纯政策提醒、企业计划公布、无争议正能量、动物奇闻
- 超过 72 小时且无新进展
- 只有标题党截图，找不到原始来源
- 灾害、事故、伤亡、血腥、未成年人隐私
- 未经证实的刑事指控、个人隐私、网暴对象
- 医疗诊断、金融荐股、投资承诺
- 低俗猎奇、地域攻击、性别仇恨
- 不适合原生字幕或无法获得合法素材

## 标题一致性检查

发布前必须同时满足：

- 标题提到具体事件对象。
- 正文前两段解释发生了什么。
- 来源与正文结论一致。
- 没有把“网传”写成“已经发生”。
- 没有把“辟谣”写成“默认承认”。
- 没有使用无法核验的绝对化表述。
