# 抖音站内热点发现

## 硬门

每次热点扫描都必须查询抖音站内，不得只依赖微博、今日头条、B站、知乎等站外来源。抖音站内证据至少覆盖以下一种，优先组合使用：

1. 抖音官方热点榜：`https://www.douyin.com/hot`
2. 抖音热榜接口：`https://www.iesdouyin.com/web/api/v2/hotsearch/billboard/word/`
3. 已登录的抖音创作者中心“热点榜单”“热门话题”和“热门视频”
4. 抖音站内搜索结果及其“相关搜索”

公开热榜接口只返回有限榜单，不等于抖音全部热点。只查接口或只看站外热搜，会漏掉品牌、产品、数码、消费服务等正在通过搜索和推荐流发酵的话题。

## 搜索热点发现

品牌、产品或功能类事件经常先以“搜索词”出现，尚未进入热榜 Top 榜。发现流程如下：

1. 用 Codex 内置浏览器打开 `https://www.douyin.com/hot`，记录榜单时间和前 50 项。
2. 读取公开热榜接口，补充排名和 `hot_value`。
3. 对候选词和类别种子逐个打开抖音站内搜索：

   ```text
   https://www.douyin.com/search/<URL编码关键词>?type=general
   ```

4. 记录搜索页中的最近视频发布时间、播放/互动展示和“相关搜索”。
5. 对相关搜索继续做一次站内搜索，确认是否已经形成完整事件名、当事方回应或主流媒体跟进。
6. 只有站内搜索热度不够，必须再用权威媒体或当事机构核验事实；站内热度不是事实本身。

类别种子包括但不限于：

- 品牌或产品名 + `回应、被指、争议、广告、故障、处罚、道歉`
- 产品功能 + `急救、隐私、自动扣费、锁屏、登录、退款`
- 消费服务 + `加盟、维修、会员、套餐、退货、收费`
- 社会民生 + 学校、医院、物业、交通、就业、住房、婚恋

## “荣耀魔法画报”示例

在 2026-09-12 实测中，抖音官方热榜当刻没有出现“荣耀魔法画报”，但站内搜索已经能看到数小时内的视频，并出现以下相关搜索：

- 荣耀魔法画报被指耽误心梗救治
- 荣耀回应魔法画报问题
- 荣耀魔法画报是什么
- 魔法画报广告错失抢救
- 荣耀手机魔法画报被质疑耽误急救

这说明仅查热榜会直接漏题。正确做法是搜索 `荣耀魔法画报`，展开相关搜索，确认发布时间和当事方回应，再决定是否进入事实核验。涉及急救、医疗或生命安全的表述必须等待权威来源和当事方完整回应，不得只凭用户视频下结论。

## 站内证据字段

状态文件的 `douyin_evidence` 至少记录：

```json
{
  "hot_board_rank": null,
  "hot_value": null,
  "search_query": "荣耀魔法画报",
  "related_searches": [
    "荣耀魔法画报被指耽误心梗救治",
    "荣耀回应魔法画报问题"
  ],
  "recent_video_examples": [
    {
      "published_at": "2026-09-12T00:00:00+08:00",
      "author": "示例账号",
      "observed_views": 159
    }
  ],
  "observed_at": "2026-09-12T02:30:00+08:00"
}
```

未进入热榜但站内搜索有近期视频和相关搜索时，`hot_board_rank` 必须写 `null`，并说明证据来自搜索热点。不得把搜索结果伪装成热榜名次。
